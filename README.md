# Koi & Cosmos

A calm wellness web app: koi pond stand-up walk timer, focus music (optional Spotify), a wake alarm and cosmic themes drawn from your birth chart.

**Open the app:** https://naekitakadoportfolio.github.io/koi-cosmos/

- Installable PWA, works offline
- All data stays on your device (local storage); see [privacy.html](privacy.html)
- The wake alarm rings only while the app is open (phones pause web apps when locked)

Built by Nae Kitakado. Uses [Astronomy Engine](https://github.com/cosinekitty/astronomy) (MIT).
